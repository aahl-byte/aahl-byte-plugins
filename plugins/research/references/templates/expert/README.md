# <Domain> expert store

The store behind `.claude/agents/<name>-expert.md`. The expert owns <the seam, in one sentence>.

- `STATUS.md` — where things stand now. Read it first.
- `notes/` — one dated finding per file, never edited after it is written. Each states what was measured,
  on what, the number, and the regime it holds in, and records the attacks that failed.

The code outranks this store. A stale entry gets a new note, and `STATUS.md` is repointed to it.
