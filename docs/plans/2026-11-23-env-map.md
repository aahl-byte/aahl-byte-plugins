# env-map implementation plan

Builds rollout step 2 of `2026-11-23-env-map-design.md`: the `plugins/env-map` plugin, its four views, its pattern flags and the `env-map check` gate, with the Section 3 proofs. Every task is test-first with `node --test`: write the test, run it and see it fail, write the code, run it and see it pass, commit.

Run all tests with `cd plugins/env-map && node --test test/`. Each task names the one test file it adds.

## End state

- `node plugins/env-map/bin/env-map.mjs map --root /mnt/rain/work_files/inspection-app` writes `.claude/env-map/graph.json`, `.claude/env-map/index.html` and `.claude/env-map/snapshots/<date>.json` there.
- `node plugins/env-map/bin/env-map.mjs check --root <project>` prints each gate failure with its file and field, a count of parts missing a why split ours and external, and exits 1 on any failure in a part we own.
- A SessionStart hook in `plugins/env-map/hooks/hooks.json` starts `map` detached and exits 0.
- `claude plugin validate plugins/env-map` passes.

## Data model

`graph.json` holds `roots`, `sources`, `boxes`, `edges` and `flags`, every array sorted and every object written with sorted keys.

- **Box ids** are relative to their root so a git-ref baseline and a snapshot use the same ids: `script:repo:scripts/check.mjs`, `rule:repo:scripts/check.mjs#tsconfig-untouched`, `hook:global:~/.claude:PreToolUse:0.0`, `skill:plugin:thinking@aahl-byte:writing-style`.
- **Edge kinds:** `fires` (event to hook, git hook, deny rule, `CLAUDE.md`), `calls` (hook or git hook to script), `contains` (script to rule, `CLAUDE.md` to table row), `enforces` (script, rule or git hook to the row it enforces), `names` (skill or agent to another it names as `plugin:name`).
- **Reach** is the set of events upstream of a box; **blast radius** is everything reached forward over `calls`, `contains` and `enforces`, and backward over `names`.
- **Owner:** the project repo and plugins from marketplaces listed in `config.json` are ours; everything else is external and carries its source and version.
- **Unreadable sources** become a box of kind `unreadable` carrying the error, plus a `sources` entry with status `error`.

## Global config dirs

Read `CLAUDE_CONFIG_DIR` when set, `~/.claude`, and each config dir that `installed_plugins.json` install paths sit under (`<dir>/plugins/cache/...`). Deduplicate files by realpath and label each file by the config dir whose realpath contains it.

## Tasks

1. **Scaffold.** `plugin.json` (thinking's format), `package.json`, `.gitignore` for `node_modules`, marketplace entry, `npm run vendor`. Proof: `claude plugin validate plugins/env-map` exits 0.
2. **Text helpers.** `test/text.test.mjs`: frontmatter keys and flow lists; `export const meta` read without running the script; `RULES` objects with id, why, layer, takes and `match` regex, including regex literals holding brackets; a regex sample that its own regex matches.
3. **Settings parser.** `test/settings.test.mjs`: hooks per event and matcher, the called file resolved through `$CLAUDE_PROJECT_DIR`, `${CLAUDE_PLUGIN_ROOT}` and `f=...`, inline commands marked, deny rules with patterns, invalid JSON giving an unreadable box.
4. **Git hooks, scripts, CLAUDE.md, markdown parts, plugins.** One test file each: `githooks`, `scripts`, `claude-md` (table rows and enforcer tokens), `markdown` (skills, agents, memories, names), `plugins` (user scope plus matching local scope, disabled plugins skipped, ours by marketplace).
5. **Golden graph.** `test/golden.test.mjs`: collect `test/fixtures/golden` and compare with `test/golden/graph.json` byte for byte; the expected file is written by hand from the fixture before the graph code exists.
6. **Reach and blast radius.** In `test/graph.test.mjs`: a script reached from Stop, SubagentStop and pre-commit reports those three events, and its blast radius holds its rules and the rows they enforce.
7. **Flags.** `test/flags.test.mjs`, one fixture per flag: crowded event, overlap, unenforced prose (row and recent prose skill), churn (temp git repo with fixed commit dates), cross-boundary edge, orphan (script and skill).
8. **Gate.** `test/gate.test.mjs`: a fixture with a script missing `why` fails and names file and field; adding the field passes; inline hook, bad layer and unknown `takes` each fail; external parts are counted but never fail.
9. **Baselines.** `test/baselines.test.mjs`: a git-ref baseline built from a temp repo shows the added hook; snapshots are one per day and identical ones collapse.
10. **Render.** `test/render.test.mjs`: the page holds ELK, the graph and the baselines inline, loads nothing remote, and two renders differ only on the timestamp line.
11. **CLI and determinism.** `test/cli.test.mjs`: `map` twice on the golden fixture gives byte-identical `graph.json` and HTML apart from the timestamp line; `check` exit codes.
12. **SessionStart hook.** `test/session-start.test.mjs`: the hook exits 0 within a second and the page appears. Then the end-to-end probe `test/e2e-session.sh`: `claude -p` with `--plugin-dir plugins/env-map` in a fresh temp git repo regenerates `.claude/env-map/index.html`.
13. **Real run.** `map` and `check` on inspection-app; screenshot every view with Playwright from inspection-app into `tmp/env-map-shots/`; fix whatever draws badly.
14. **Ship.** Push, PR into `master`, merge with a merge commit, `claude plugin marketplace update aahl-byte`.
